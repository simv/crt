# Spike: where can the extension send feedback with no CRT server? (2026-11-18)

For PRD-connect. What was read and what was run, and what is still unproven.

| # | Question | Finding | How |
|---|---|---|---|
| 1 | Can another product sign in to a Claude account, list its projects or sessions, or post into one? | No public interface. Subscription sign-in is reserved for Anthropic's own products and has been enforced against other tools since early 2026. | Docs and press coverage, 2026-11-18. Not Anthropic's terms read first-hand. |
| 2 | Can a web request start a Claude Code session in a repository? | Yes: a scheduled task ("routine") with an API trigger. `POST https://api.anthropic.com/v1/claude_code/routines/<trig_…>/fire`, `Authorization: Bearer sk-ant-oat01-…` (a token of that one task, generated by hand at claude.ai/code/routines and shown once), body `{"text": "…"}` up to 65,536 characters, text only. Answers `claude_code_session_id` and `claude_code_session_url`. 30 fires an hour per task, 100 per account. Research preview; the address is marked experimental. | https://code.claude.com/docs/en/routines and https://platform.claude.com/docs/en/api/claude-code/routines-fire |
| 3 | Does the address exist and behave as documented? | A request with a made-up task id and token answers `401 {"type":"error","error":{"type":"authentication_error","message":"OAuth access token is invalid."}}` with the headers `anthropic-version: 2023-06-01` and `anthropic-beta: experimental-cc-routine-2026-04-01`. No CORS header in the answer, so the request has to come from an extension context holding the host permission, not from a page. | `curl` from a cloud session, 2026-11-18 |
| 4 | Can tasks or tokens be listed or created from outside? | No. One paste per repository is the floor. | The same docs |
| 5 | Can the overlay run with no server and no change to itself? | Yes: its transport already ends in the worker, which can answer the routes itself. | Built: `packages/overlay/src/extension/standalone.ts`, `e2e/extension.spec.ts` |

**Not proven:** a real fire from the extension, the session it starts, and what the task does with the text. That needs a token only Simon can generate (PRD-connect M41, Manual).

The two docs pages disagree on headers (one shows `anthropic-version: 2026-10-21` with the beta header optional). The extension sends the pair row 3 was answered with.
