Where each site's reviews go

A review goes to the project whose CRT server the site talks to, or stays in this browser until you send it. Pick one for each site you have turned CRT on for. Open the review in this browser

    CRT servers running on this machine

      Run crt in a project's folder to start its server. The first takes port 4400, the next 4401, and so on.

      Send to Claude

      With no CRT server, a review can start a Claude Code session in a repository. Claude gives each scheduled task its own address and token; this is the one place they are kept, and they are used only when you press Send on the review page.

        1. Open Claude's scheduled tasks and create a task for the repository.
        2. Give it a prompt:
        3. Edit the task, add an API trigger and generate its token.
        4. Paste the address and the token here. Pasting the whole example command into either field works too.

        Used when sites with no choice of their own go to a CRT server.
