## Summary
`http://localhost:4400/` is a paragraph. Make it the page a developer is glad to land on: the mark, `This is the CRT server — not your app.` over `Your app is at …` with an **Open** button (three hero states), an **Attention** block only when `crt doctor` would flag something, the loop in three cards, a **Checkup** with the doctor's row text grouped by status (problems first, passes collapsed, copy buttons on the commands), this server's facts and provider states, the three Claude Code skills, and a tube that powers on once. Server-rendered and complete without JavaScript; one inline script; same-origin fetches only; dark mode; reduced motion respected; AA contrast; ≤ 32 KB. Behind it, `GET /__crt/doctor` serves the doctor rows computed inside the running server, refuses cross-origin callers, and keeps the slow plugin row opt-in and cached. `docs/PRD-polish.md` §5.2, F-113, F-114, N-23, N-24, N-25.

## Context
The current page is `landingPage()` in `packages/server/src/proxy.ts` (F-91: plain words, no scripts), served for every non-`/__crt/` request in embedded mode; `test/proxy.test.ts` "answers every non-/__crt/ request with the landing page … no scripts (F-91)" and `e2e/embedded.spec.ts` "health says embedded, / is the landing page …" assert `not.toMatch(/<script/)` — PRD-polish §9 amends F-91 so those become "exactly one inline `<script>`, no `src`", and the kicker's wording changes to `This is the CRT server — not your app.`. The doctor is `packages/server/src/doctor.ts`: `doctorRows(facts)` is pure over `DoctorFacts`; `collectDoctorFacts({ target, plugin, providers, mode })` gathers them with localhost probes; the `port` fact probes the port and would find this very server (`state: "crt", thisProject: true` → a `FAIL` row) — a new `state: "self"` is needed; `pluginFact` spawns `claude plugin list --json` with a 10 s timeout. Health is `healthPayload()` in `proxy.ts` (`version`, `startedAt`, `mode`, `app`, `projectRoot`, `tasksDir`, `tasks`, `provider`, `login`, `sessions`, `overlay: { injected, fetched, loader, … }`); the registry is `opts.providers` (`ProviderRegistry`: `status()`, `resolve()`, display names for F-56); `serve.ts` builds `ProxyOptions`. `/__crt/internal/*` already refuses any request with an `Origin` header — reuse that check. The concept is `docs/design/landing-mockup.html` (static data; open it) and the design review's changes in `docs/design/design-review-2026-09-21.md` §B are the ones to apply (PRD-polish §5.2 restates them and wins on conflict). The mark comes from M20 (`docs/brand/crt-mark.svg`, `-dark`, `-small`; favicon at `/__crt/favicon.svg`; colours in `packages/overlay/src/tokens.ts`).
