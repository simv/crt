## Summary
CRT has no mark. Turn the chosen direction from the five tube-TV options in `docs/brand/options/` into the brand's file set — mark, dark mark, pixel-snapped small mark, lockup, dark lockup, favicon — with the design review's fixes (Bézier corners, badge centred on the edge with a background ring, no glass highlight, a dark bezel variant), write the ten-line usage rules, move the overlay's colours into one `tokens.ts` that the overlay reads, serve the favicon at `/__crt/favicon.svg`, copy it into `dist/` at build time, and pin the files with a unit test. `docs/PRD-polish.md` §5.1, F-112, N-25.

## Context
The five directions (A Tube, B Sign-off, C Select, D Speak, E Monogram) were generated on 2026-09-21 by `docs/brand/gen-logo.mjs` as 96-point superellipse polylines (|x/a|⁴ + |y/b|⁴ = 1, a 4:3 box, ink `#111`, accent `#ff3d71` — the overlay's marker colour, `ACCENT` in `packages/overlay/src/screenshot.ts` — glass `#2b2b31`); `docs/brand/options/contact-sheet.html` renders each at 128 / 48 / 32 / 24 / 16 px, in the launcher pill, on light and dark (open it in a browser; regenerate with `node docs/brand/gen-logo.mjs`). The design review (`docs/design/design-review-2026-09-21.md` §A) ranked them A › B › C › E › D, found no better sixth, and listed the fixes before A ships — they are restated in the Ask. The chosen direction is **A (Tube)** — Simon's pick, recorded in PRD-polish §13 decision 1 on 2026-09-21. Overlay colours today: `ACCENT` in `screenshot.ts`; the launcher (`#111` pill, `#2e9e5b` connected dot), the status pills (`#fff3cd`/`#7a5a00`, `#dbe7ff`/`#1a4d99`, `#d9f5e3`/`#0a5b2b`, `#fde2e2`/`#8b0000`) and the badge in `ui.ts`'s CSS template. Static assets reach `dist/` through the server build (`plugin/skills/intake/SKILL.md` → `dist/intake.md`, `plugin/` → `dist/plugin-marketplace/`; see `packages/server/package.json` `build` and `scripts/integrations.mjs`); `/__crt/*` routes live in `packages/server/src/proxy.ts` (`handleCrtRoute`); `early.js` / `loader.js` are served from `dist/` beside `overlay.js` (`siblingOf`). The F-6 CORS rules apply to every `/__crt/*` GET. Overlay unit tests import `../../overlay/src/*` directly from `packages/server/test` (e.g. `owner-stack.test.ts`).

## Ask
1. **Files** under `docs/brand/`, from the chosen direction, per PRD-polish §5.1: `crt-mark.svg` (128 grid; ink bezel, `#2b2b31` glass, the badge), `crt-mark-dark.svg` (bezel `#f2f2f4`, glass unchanged, badge glyph white), `crt-mark-small.svg` (`viewBox="0 0 16 16"`, whole-pixel coordinates, solid ink tube, no glass, a plain dot ≥ 3.5 px instead of the numeral), `crt-lockup.svg` and `crt-lockup-dark.svg` (mark + the wordmark "CRT" as outlined paths — draw the glyphs as geometry or outline a permissively licensed geometric sans; no `<text>`, no font reference; heavy enough to survive 24 px), `favicon.svg` (the small variant with an in-SVG `<style>@media (prefers-color-scheme: dark) { … }</style>` switching the bezel; ≤ 2 KB). Fixes from the review: cubic Bézier corners (continuous curvature), the badge centred on the superellipse edge (compute the point on the curve, not `98,30`), a 2-unit ring in the background colour on the badge (`paint-order="stroke"` with `stroke` = background), no diagonal glass highlight, nothing thinner than 1/16 of the mark's height. Every SVG: `viewBox`, no root `width`/`height`, no external reference, ≤ 4 KB. **Should:** `favicon-32.png` and `favicon-16.png` rendered from the small mark (Playwright), ≤ 2 KB each, served at `/__crt/favicon-32.png` / `-16.png` only if cheap.
2. **`docs/brand/README.md`**: ten lines — which file where (README hero, npm README, landing header, favicon), the mark alone below 24 px and the lockup above, clear space one bezel width, minimum 16 px, never recolour beyond the two variants, never rotate, the accent only in the badge; a line pointing at `options/`, `gen-logo.mjs` and the design review as the record.
3. **`packages/overlay/src/tokens.ts`**: exports the ink, the accent, the launcher/health greens, the status pill pairs and the badge colour; `ui.ts` and `screenshot.ts` read from it (template interpolation); the rendered overlay CSS is byte-identical before and after — a unit row that snapshots the CSS string from `ui.ts` (or the built `overlay.js` size and a grep for each hex) proves it. `CLAUDE.md` Conventions gains the line in PRD-polish §9.
4. **Route** `GET /__crt/favicon.svg` (F-112): `image/svg+xml`, `cache-control: max-age=86400`, the F-6 CORS headers, both modes; `HEAD` allowed, other methods 405. The build copies `docs/brand/favicon.svg` (and the PNGs if made) to `packages/server/dist/` — extend the existing copy step, not a new script; the route serves it as `siblingOf(overlayPath, "favicon.svg")`.
5. **Test** `test/brand.test.ts`: for each SVG — parses with an `<svg>` root, `viewBox` present, no root `width`/`height`, no `<text>`, `<image>`, `<script>`, `href` or `xlink:href`, no `<style>` except in `favicon.svg`, size under budget (N-25), the dark files contain no `#111`; the small mark's coordinates are integers. A route row in `test/proxy.test.ts` (200, content type, cache header, CORS for a loopback `Origin`, 405 on POST). One assertion in `e2e/embedded.spec.ts`'s F-91 test that `GET /__crt/favicon.svg` on the stub server answers 200 `image/svg+xml`.
6. **Contact sheet**: add a "Final" row to `docs/brand/options/contact-sheet.html` (hand-edit; the generator still emits the five) that inlines `crt-mark.svg` at 128/48/32 and `crt-mark-small.svg` at 24/16, the dark files in the dark card, and the **dark variant** inside the pill cell on both cards (the real pill is always `#111` — `ui.ts` line ~66 — so the sheet's inverted pill on dark was a fiction; fix the card CSS too). Render the sheet at DPR 1 and 2 with Playwright into `docs/brand/renders/` (two PNGs, ≤ 300 KB each).
