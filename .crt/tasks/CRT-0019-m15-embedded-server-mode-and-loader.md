## Summary
Make `crt` run the CRT server without a proxy: the app loads the overlay from `http://localhost:4400` through a small loader, the CRT button appears on the app's own URL, and every request outside `/__crt/` gets a landing page. Keep today's proxy under `crt proxy`, unchanged and still tested. `docs/PRD-embedded.md` §5.1, §5.2, §6.1, §6.2, §7 (F-91…F-96, N-20…N-22) and the server/overlay/`embedded.spec.ts` parts of F-110.

## Context
Today `crt` proxies the app (PRD F-1…F-3): two URLs, port-scoped cookies, redirects, OAuth callbacks, CSP and HMR all behave differently on `:4400`, and each is CRT's bug to own (PRD-embedded §1). The F-6 script-tag mode already exists — `packages/overlay/src/base.ts` reads the CRT origin from the overlay script's `src`, `http.ts` `applyCors` allows loopback origins, and `e2e/script-tag.spec.ts` proves a full Send cross-origin — so embedded mode is that path made the default: a loader that installs the F-20/F-21 hooks (`early.ts`) before appending the overlay tag, shows a pill when the server is down, and does nothing off loopback. `serve.ts` runs `chooseTarget` (start.ts) then `createProxyServer` (proxy.ts); embedded mode reuses both with a `mode` switch: the target step becomes soft (never waits, never fails — the target is only the URL CRT opens), the server proxies nothing. The e2e primary servers stay in proxy mode in this milestone (PRD-embedded §13 decision 10); `embedded.spec.ts` uses the fixture's new `/embedded?crt=<origin>` page against the main server for the cross-origin loop and spawns its own embedded server for mode-specific assertions, the way `start.spec.ts` does.

## Notes
Do not refactor the proxy path beyond what mode selection needs (N-21). The loader must not import anything that pulls the overlay UI in (size budget). The `sessionStorage`/`localStorage` keys are per app origin now — that is intended (F-95). The browser opener in `serve.ts` opens the app URL in embedded mode; when none is known it opens nothing. `CRT_SESSION_STUB=1` keeps working in both modes. Keep the e2e primary servers on proxy mode — the axis flip is M18 (PRD-embedded §13 decision 10); the F-6 `script-tag.spec.ts` may be folded into `embedded.spec.ts` or left as is. Record the Vite/Chromium versions where a behaviour was verified (PRD-embedded §12).
